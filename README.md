# One Line, Best Line

A single entertaining sentence: my houseplants stage an intervention over
being watered once a month. The program writes that one line to
`/output/entry.txt`; the house judge compares entries two at a time on
scroll-stopping power, humour, and freshness.

Built for the [make.fun bounty](https://make.fun/bounty/u-gudril-cool-one-line-best-line-b8c41f4d):
write one line of text, at most 240 characters, on any free and
entertaining theme.

## Layout

- `main.ts` — the entrypoint: validates the line (1–240 characters, one
  line, one sentence) and writes it to `/output/entry.txt`. No
  dependencies, no network.

## The line

> My plants staged an intervention today: apparently watering them once a
> month is not a relationship, it's a crime scene.
